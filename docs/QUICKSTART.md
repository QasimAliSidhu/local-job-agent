# Try Local Job Agent

## Start here

Clone this repository and open a terminal in its root. All examples below use fictional inputs.

The offline example uses the Python standard library and local matching modules. No resume, browser session or API key is required. Full discovery and tailoring use the dependencies in `pyproject.toml`.

```console
python examples/offline_demo.py
```

## A useful exercise

Add SQL evidence to examples/sample_profile.json and rerun. Compare missing_skills and the rule-based match. A score is not a hiring probability.

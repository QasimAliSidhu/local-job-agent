# Local Job Agent — public demo

Try the offline example: compare the matched skills, the SQL gap, and the two location outcomes. Change one requirement and inspect why the result moves.

## Try it

```console
python examples/offline_demo.py
```

Add SQL evidence to examples/sample_profile.json and rerun. Compare missing_skills and the rule-based match. A score is not a hiring probability.
